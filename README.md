# Maze Thales — Fitness Studio Spijkenisse

Statische website voor Maze Thales Fitness Studio (privé personal-trainingsstudio in Spijkenisse).

## Structuur
- HTML-pagina's in de root (`index.html`, `over.html`, `dienst.html`, `tarieven.html`, `contact.html`, enz.)
- `styles.css` — alle styling
- `script.js` — interacties (coverflow, sliders, menu, toggles)
- `assets/` — afbeeldingen, video, iconen en gedeelde scripts
  - `partials.js` — gedeelde header/footer + contact-widget
  - `diensten-data.js` — data + render voor de dienstpagina's
  - `reviews.js` — echte Google-reviews (marquee)
  - `preloader.js` — laad-animatie
  - `icons/` — SVG-iconen

De originele fotobestanden (`Foto_s/`) staan bewust niet in de repo; op de site worden geoptimaliseerde versies in `assets/` gebruikt.
